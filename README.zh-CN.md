# LumaPaw

一只在 Mac 上陪你玩耍的发光小狗，外观灵感来自你家狗狗的照片。伸手摸摸它，用手势引导它，或者用声音叫它过来。

由 Cater Dai 在 **StormHacks 2026** 期间独立完成。

## 下载与打开

[下载 Mac 应用](https://github.com/Caterrr/LumaPaw/releases/latest) · [英文项目说明](README.md)

需要 **Apple 芯片 Mac（M1 或更新）和 macOS 14 或更新版本**。

1. 下载 `LumaPaw-macOS-55.0.zip` 并解压。
2. 把 `LumaPaw.app` 放进“应用程序”，然后打开。
3. 点击 Start，先体验鼠标操作。
4. 切换手掌或麦克风图标，使用手势或英文语音。按提示允许摄像头、麦克风和语音识别权限。

这是未经 Apple 公证的黑客松开发版本。如果 macOS 阻止首次打开，可以到“系统设置 → 隐私与安全性”中，为这个应用选择“仍要打开”，再确认打开。

## 怎么玩

- **鼠标**：移动指针引导小狗，在小狗身上按住鼠标进行抚摸。
- **手势**：伸出手指引导小狗，张开手掌抚摸它。
- **语音**：试试 “Luma”、“Come here”、“Sit”、“Spin” 或 “Good boy”。
- **网球图标**：开始追球互动。
- **爪子图标**：切换小狗。
- **照片图标**：导入狗狗照片；滑杆图标调整外观。
- **Escape**：返回首页。

三种输入模式一次只运行一种，首页不使用摄像头和麦克风。照片功能会参考照片调整现有模型的外观，并非任意犬种的完整三维重建。

鼠标或手势抚摸持续两秒后，小狗会坐下并出现爱心；松开后重新站起。

Release 中的 `LumaPaw-Demo.mp4` 是早期 v49 版本的 54 秒演示，不包含所有 v55 更新，使用应用渲染器和脚本交互输入制作，不是实时摄像头或麦克风录屏。
